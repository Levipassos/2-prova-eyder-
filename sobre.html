Créditos e Agradecimentos

Este projeto utiliza a API do The Movie Database (TMDB) para obter informações sobre filmes e séries.

O TMDB é uma base de dados colaborativa que disponibiliza informações sobre filmes, séries e programas de TV de forma gratuita para desenvolvedores.

Agradecemos ao TMDB por fornecer uma API robusta e documentação completa que tornou este projeto possível.
